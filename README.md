# GREENPULSE

Smart Urban Green Infrastructure Management & Intelligence Platform

## Purpose

GREENPULSE is a full-stack platform designed to help cities manage parks, trees, urban forests, green belts, maintenance activities, and citizen-reported environmental issues.

## Technology Stack

- Frontend: React + TypeScript
- Backend: Node.js + Express.js
- Database: PostgreSQL
- Cache: Redis
- API: REST
- DevOps: Docker
- Version Control: Git + GitHub
